All commands should be run after activating your virtual environment:
  source /home/parthu/python_aiml_projects/.venv/bin/activate

--------------------------------------------------------------------------------
1. DEMONSTRATION (Fastest: Run complete evaluation in ~8 seconds)
--------------------------------------------------------------------------------
Command:
  python main.py

What it does:
  - Tests SAC, DDPG, and all classical rules (Static WFQ, c-mu, PQ, LCQ).
  - Evaluates on standard topology + 10 distinct traffic scenarios (5 Train, 5 Unseen Test).
  - Displays consistent metrics: Avg Reward, Drops, Delay, Throughput, Starvation, Jain's Index.
  - Updates plot_generalization_comparison.png.

Quick Variant (Standard topology only, takes ~3 seconds):
  python main.py --standard-only

--------------------------------------------------------------------------------
2. TRAINING (How to train models yourself)
--------------------------------------------------------------------------------
Option A: Train BOTH DDPG & SAC on the 5 Traffic Scenarios (~3 minutes)
Command:
  python main.py --train --episodes 120

What it does:
  - Trains DDPG across the 5 training scenarios (saves checkpoint_ddpg_generalization.pth).
  - Trains SAC across the 5 training scenarios (saves checkpoint_sac_generalization.pth).
  - Evaluates both trained models against baselines on unseen test scenarios.

Option B: Train Both Agents from scratch on Standard Topology (~2 minutes)
Command:
  python compare_agents.py

What it does:
  - Trains DDPG and SAC for 350 episodes from scratch.
  - Saves checkpoint_ddpg.pth and checkpoint_sac.pth.
  - Generates plot_ddpg_vs_sac.png.

--- CORE ENGINE & LOGIC ---
• queue_env.py
    The discrete-time network simulator. Models the tandem router topology,
    8 DiffServ priority queues, work-conserving WFQ capacity distribution,
    packet arrival generators, buffer drops, and dual delay/drop penalty costs.

• baselines.py
    Contains the classical non-AI scheduling algorithms:
    - c-mu Rule: Mathematical optimal delay rule under linear holding costs.
    - Longest Connected Queue (LCQ): Serves queue with maximum instantaneous backlog.
    - Static WFQ: Fixed priority-tiered bandwidth weights.
    - Strict Priority Queueing (PQ): Highest priority non-empty queue gets 100%.
    - Fixed Split: Equal 1/8 bandwidth sharing.

• ddpg_agent.py
    Implementation of the Deep Deterministic Policy Gradient (DDPG) algorithm.
    Contains Actor, Critic, Replay Buffer, and Ornstein-Uhlenbeck exploration noise.

• sac_agent.py
    Implementation of the Soft Actor-Critic (SAC) algorithm.
    Features Twin Q-Critics (clipped double-Q) and automatic entropy temperature tuning.

• scenarios.py
    Defines the 10 distinct traffic scenarios (5 training scenarios and 5 reserved
    out-of-distribution unseen test scenarios) with unique arrival rates, burst
    probabilities, and dynamic microburst shock profiles.

• metrics.py
    Standardized network performance and fairness calculations:
    - Average Queue Delay (via Little's Law)
    - Packet Drops & Packet Loss Rate
    - Throughput (packets per tick)
    - Queue Starvation Incidents
    - Jain's Fairness Index (Demand Satisfaction Ratio)

--- EXECUTION SCRIPTS ---
• main.py
    The master entrypoint for the entire project. Run without arguments to test everything,
    or use --train to train both agents on the multi-scenario environment.

• evaluate_generalization.py

• compare_agents.py
